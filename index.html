Versi aplikasi. Yang menentukan bentuk JSON adalah nomor mesin sing-box, bukan siapa yang membuat aplikasinya. reF1nd adalah build pihak ketiga, SFA adalah aplikasi resmi SagerNet. Di 1.13 ke atas, outbound block dan dns sudah dihapus. Di 1.14 format DNS lama ikut dihapus. Kalau salah pilih, aplikasi menolak saat Save.

Dashboard dan alamatnya. Nama folder tempat file dashboard disimpan di HP harus sama persis dengan isian di sini. Alamat memakai 127.0.0.x karena dashboard melayani aplikasi di HP sendiri, bukan diakses dari luar. Kalau halaman tidak terbuka, biasanya port dipakai aplikasi lain — ganti angka setelah titik dua.

Jumlah grup auto. Akun dibagi selang-seling ke Primary, Backup, dan Tertiary supaya tiap grup dapat campuran protokol. Gunanya agar trafik tidak menumpuk di satu server yang kebetulan paling cepat.

Kecepatan cek server. Ini jarak waktu tiap kali semua akun diuji. Untuk 30 akun lebih, 20 detik berarti ratusan pengujian per jam — boros baterai dan grup gonta-ganti terus. Toleransi ikut menyesuaikan supaya selisih ping kecil tidak bikin pindah server.

Blokir QUIC. QUIC adalah jalur UDP port 443. Jalur ini sering lolos keluar tunnel sehingga kuota utama terpakai. Kalau ditutup, aplikasi turun ke TCP dan tetap lewat tunnel. Pemilahan per domain bekerja karena config ini punya sniff di inbound TUN.

Bendera bawaan. Lokasi tidak bisa ditebak dari IP karena Cloudflare memakai anycast. Bendera diambil dari nama akun atau nama host, misalnya sgdo1 dibaca sebagai Singapura. Yang tidak terbaca memakai bendera bawaan ini.

WhatsApp jalur langsung. Menambah aturan nama paket com.whatsapp supaya keluar lewat direct. Aturan ini diletakkan di atas aturan QUIC, jadi WhatsApp aman walaupun semua UDP 443 diblokir.

Bagi akun ke beberapa grup. Sing-box tidak punya load balance seperti Clash, jadi cara yang setara adalah membagi akun ke beberapa grup Auto. Tiap grup memegang akun berbeda, dan Anda bisa berpindah grup lewat dashboard kalau satu grup terasa melambat. Kalau dimatikan, semua akun masuk satu grup dan pilihan jumlah grup diabaikan.

Pisahkan grup per protokol. Akun port 80 tidak melakukan jabat tangan TLS, jadi ping-nya hampir selalu paling rendah dan akan selalu menang kalau dicampur dalam satu pengujian. Dipisah supaya VLESS TLS, VLESS non-TLS, VMess, dan Trojan masing-masing punya juara sendiri.

Lewati verifikasi sertifikat. Sama dengan allowInsecure di v2rayNG. Sertifikat tetap dipakai untuk mengenkripsi, hanya kecocokan namanya yang tidak diperiksa. Untuk akun lewat IP bug yang SNI-nya satu tingkat subdomain, biasanya tetap lolos meski pilihan ini dimatikan.
